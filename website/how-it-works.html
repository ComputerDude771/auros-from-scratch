How it works

One file, one restart, and a way back at every step.

You click through a wizard, then wait. This page is what the wizard is doing while you wait, written for someone who has never needed the word “partition” and still does not.

One word

Partition

A drive is one physical thing, but the computer divides it into labelled areas called partitions, the way a warehouse is divided into bays. Windows lives in one. Installing AurOS makes that bay smaller and builds new bays in the space freed. Everything in the Windows bay stays where it is.

The list of bays is kept at the front of the drive. AurOS changes that list in one write of one small piece of the drive, after everything else is in place. Before that write, the old list is true; after it, the new one is.

Step by step

The phase numbers are the ones in docs/AURBRIDGE.md. The interactive version shows the disk at each step.

In Windows. Nothing on the drive is resized or rewritten.

  1. 0

    Check this PC

    Reads the firmware mode, the drives, their health, encryption, Fast Startup, power, and whether the firmware trusts the key AurOS’s start-up files are signed with. It writes nothing. If something is wrong it says so in one line, and Fix these for me fixes what a program can fix.

  2. 1

    You agree

    What will change, in plain words, and how to undo it. Nothing has happened yet.

  3. 2

    Download and prepare

    About 1.8 GB, in pieces, each checked, resuming if the connection drops, unpacked into C:\AurOS and checked whole before it is used. Its start-up files go onto the PC’s EFI partition, under \EFI\AurOS and nowhere else.

  4. 3

    Ask the PC to start the installer once

    A one-time request to the firmware, which the firmware forgets as soon as it uses it. The PC’s normal start-up order is not touched.

The one restart

After the restart. Plain text on the screen, the same boot throughout.

  1. –

    Check everything again, and save the way back

    Every check runs again. A copy of how this PC starts Windows (its partition table and its EFI partition) is taken and read back before anything is changed.

  2. 4

    Make Windows smaller

    With Windows not running, using the long-established tool for resizing Windows’ filesystem rather than one of AurOS’s own. Only the filesystem shrinks; the partition list still says Windows is its old size, and a partition bigger than its filesystem starts normally. This is the one step that cannot be undone, and the one moment the screen says not to switch off.

  3. 5–6

    Write AurOS, read it back

    Without a memory stick, the way back is written into the freed space first and checked. Then AurOS is copied into the freed space, by position, with the old partition list still in force, and read back to make sure every byte is right.

  4. 8a

    Make the PC able to start AurOS

    AurOS’s own start-up partition is written into the freed space too, still before the list changes.

  5. 7

    Check this PC works under AurOS

    Loads the drivers from the AurOS just written and looks for wireless or a network cable, screen brightness and sound. If it finds no way to get online, it stops here and the partition list is never changed.

  6. 8

    Change the list, in one sector

    The new list of partitions, then the one sector that points to it, then the spare copy at the end of the drive. The middle write is the instant the drive becomes the new shape.

  7. 8

    Join the start-up menu, and start AurOS

    AurOS is added to the firmware’s menu and asked for once; Windows stays the default. AurOS grows to fill its space and starts, in the same boot.

AurOS

In AurOS. Nothing is final until you say so.

  1. 9

    “AurOS is on this computer”

    “Right now, switching this computer on still starts Windows. That stays true until you press Yes.” Until you answer, AurOS asks the PC to come back to it once more at every start.

  2. 10

    Yes, and your files

    Yes makes AurOS what the PC starts; it is the only thing in AurOS that changes the start-up order. Then AurOS offers to bring your files across from the Windows part of the drive, which it only reads, and writes a report of what could not come.

Secure Boot stays on

Nothing is enrolled: no key of AurOS’s own, no blue “enrol a key” screen, nothing to switch off.

Each link checks the signature on the next one before it lets it run.

When a PC does not trust that key

The installer reads the firmware’s list of trusted keys from Windows, before anything is changed.
The firmware trustsThe installer
The key shim is signed with (almost every PC sold with Windows)Nothing needs changing.
No third-party key at all (some Secured-core PCs, such as some Surface and Lenovo models)Stops, and shows the one firmware setting to switch on: “Allow Microsoft 3rd Party UEFI CA”. Secure Boot stays on. What that page looks like.
Only Microsoft’s newer 2023 key, or the old one revokedStops: “This PC needs a newer AurOS installer”. No setting fixes it; it needs a shim signed with the 2023 key.
Could not be readA note, not a stop. Such a PC almost always trusts the key, and one that does not simply starts Windows again with the drive untouched.

Going back

Three ways back to Windows, from least to most.

  1. Just start Windows

    Press the PC’s start-up menu key as it switches on (often F12, F9 or Esc) and choose Windows Boot Manager. AurOS’s own start-up menu has a Windows entry too. Before you have said Yes, saying No, go back to Windows makes Windows the default again.

  2. Settings → Put Windows back

    In AurOS. The remove button has to be pressed twice. The PC restarts into the restore, which shows text while it works and then switches itself off; switched on again, Windows starts, with all of its drive back.

  3. If AurOS will not start

    AurOS’s start-up menu, the list shown for three seconds as it starts, has Put Windows back (remove AurOS). It starts the restore with Secure Boot on, without AurOS having to work.

What putting Windows back cannot do

Everything saved inside AurOS goes with it; copy what you want to keep onto a memory stick first. And in the test build, which installs without a memory stick, the way back is kept on the same drive it exists to rescue: if that drive fails, the way back fails with it.

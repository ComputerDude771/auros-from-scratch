Trying AurOS on this computer

Helping you: Their phone:

This is a test version. Use it only on a computer whose files you do not need, or whose files are copied somewhere else first.

  1. Before you start

    Charger plugged in. Memory sticks and USB drives unplugged. Internet working: it downloads about 1.8 GB.

  2. Open the file

    Windows says “Windows protected your PC”. Press More info, then Run anyway. Then Yes when it asks to make changes.

    No “Run anyway”? Stop here: this computer will not run it.

  3. Follow the pages

    If a page lists problems, press Fix these for me. On Ready, tick the box and press Start installing. The download is the long part.

  4. Press “Restart now”

    Do not close the window instead. Closing it cancels everything, on purpose.

  5. After the restart: words on a black screen

    That is normal. Do not switch the computer off while it says “Making room on the Windows drive”. It can take a while.

    If it stops with a sentence and verdict=, take a photo of the screen and send it.

  6. “AurOS is on this computer”

    Yes, it all works keeps AurOS. No, go back to Windows makes Windows start again. Windows is still there either way.

To start Windows

As the computer switches on, press the menu key (often F12, F9 or Esc; the maker’s logo often says which) and choose Windows Boot Manager.

To remove AurOS

In AurOS: Settings → Put Windows back, then press Remove AurOS and put Windows back twice. Anything saved in AurOS goes with it.

Download

The test installer, for a spare PC.

There is no public release yet. There is a test build: one unsigned .exe, for a computer whose files you do not need, or a virtual machine. This is the first time its Windows half meets real PCs, and that is what it is for.

Five boxes

Nothing you tick is stored or sent. They are here to slow you down for a minute. With JavaScript off, the link simply works.

  • The test build keeps the only copy of the way back on the same drive it changes, and it has not yet been seen to resize a real PC’s drive. A spare PC, or a virtual machine.

  • AurOS needs 28 GB once installed, Windows keeps 8 GB, and the 5 GB copy of AurOS stays on C: while it installs, plus 1.8 GB of download for a while. Almost every PC from 2013 on is UEFI. How to check.

  • About 1.8 GB is downloaded; it resumes if it drops. The installer refuses while a USB drive is plugged in, and waits for the charger.

  • “Windows protected your PC”, because the file is not signed: More info, then Run anyway. Then Yes to “allow this app to make changes”. If there is no Run anyway, Smart App Control is on and this PC cannot run it. Antivirus may hold it too; TRY-IT says what to do.

  • The screen shows text, not a desktop: that is the installer. If it stops with a sentence and verdict=…, I will take a photo of the screen and send it. A stop before “Making room on the Windows drive” has changed nothing.

Tick the five boxes above.

Check it in PowerShell with Get-FileHash .\AurOS-Installer-test.exe. If a newer build has been published since, the README beside the file has its hash and says what was tested where; it is the one to trust over this page.

What it is, and is not

Tested

  • Started, checked and navigated on real Windows, where it also downloaded and checked the whole of AurOS.
  • Installed and put back on simulated PCs with real UEFI firmware and Secure Boot on, without a memory stick, the way it runs.
  • Read over by an independent review; its seven findings fixed.

Not tested, not done

  • A real PC’s drive being resized and written. That is what a spare PC is for.
  • Signed. Windows will warn; Smart App Control will refuse it.
  • Antivirus running during an install.

Before you run it, the whole of TRY-IT is short, and this one-page version prints on a single sheet. The honesty page lists what can go wrong.

From source

Everything is MIT-licensed and builds from the repository: build/forge builds an image, build/mkimage makes it bootable, and build/aurbridge builds the installer. docs/HANDOFF-RUNBOOK.md has the exact commands, and every test in tools/ exits non-zero when it fails.

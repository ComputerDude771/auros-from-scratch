Download

Five questions before you download anything.

This program can repartition the disk your photographs live on. The checklist below is not a formality and it is not a liability shield — it is the same list our own engineers work through before running a test install on a machine they care about.

The pre-download checklist

Tick each one honestly. Nothing you tick is sent anywhere — there is no server on the other end of these boxes, and nothing is stored in your browser. They are here to slow you down for two minutes.

  • Windows 10 or 11, 64-bit, booting in UEFI mode (not legacy BIOS), with roughly 28 GB free on the Windows drive and a hard drive that is not reporting errors.

    If you are not sure — and most people are not — that is exactly what the compatibility check is for. It is read-only and answers all of this for you. The full requirement list.

  • Not another folder, not another partition on the same disk, not “most of it is in the cloud”. A separate physical drive, or a cloud copy you have actually confirmed is complete by opening a few files from it.

    Why we are strict: the step that makes room for AurOS moves files around inside your Windows partition. On a drive that has been quietly failing for years, that is the workload which finally exposes it. We check the drive’s health first and refuse if it looks bad — but a backup is the only thing that makes a bad outcome survivable.

  • The installer writes a rescue USB before it changes anything, and it will not proceed without one. Everything on that stick is erased.

    We know this costs us users who would otherwise have installed. We are taking the hit on purpose. A rescue partition on the internal disk covers “AurOS will not start”; the USB covers “the disk’s partition table is gone”. Neither one substitutes for the other, and the second case is the one that ends with a person holding a computer that will not boot at all.

  • On a laptop: the charger in the wall, and the battery above 50%. The installer refuses below that, with no override.

    Why: a partition table is not journalled. There is a single moment where the old layout stops being true and the new one starts, and losing power inside that window is the one failure mode we cannot engineer away completely. We shrink the window to one sector write, and we refuse to open it at all on battery.

  • Set aside an evening, not ten minutes. The disk check that has to pass before we touch anything can take hours on an older spinning hard drive, and it is not safe to interrupt. Do not start this at 11pm the night before you need the machine.

    If Windows encrypted your drive — which recent versions often do silently, when you sign in with a Microsoft account — you will need your 48-digit recovery key, and the installer will ask you to type part of it back before continuing. Not tick a box: type it. Find it now, on your phone or another computer, in your Microsoft account’s device page. If it cannot be retrieved, we stop, because continuing would lock you out of your own Windows for good. More on this.

Work through the checklist above.

Continue to the download

The boxes are a speed bump, not a lock. If you have JavaScript turned off, the link works normally and the checklist still reads the same.

What you can download today

AurBridge Check — read-only

A small Windows program that inspects this PC and prints a report: what passed, what we would warn you about, and what would stop us. It opens your disks for reading, reads your firmware variables, your drive’s health counters and your encryption state, and then exits.

  • Never writes to any disk, ever. There is no code path in it that can.
  • Sends nothing anywhere. It works with the network cable unplugged.
  • Prints a report you can read, and a machine-readable copy you can send to someone who knows more than you do.

The installer — a test build, for spare PCs

AurBridge’s destructive phases are written: shrinking Windows, writing AurOS, checking it, the one restart, and putting Windows back. They have been tested on simulated machines with real firmware, with the power cut at seventeen named moments, and Windows came back every time with every file exactly as it was. The installer starts on real Windows and is checked there before each test build is published.

What has not happened yet is the part that matters most: installs on many real PCs. Until it has, the test build is for computers whose files you do not need, it is not signed, and it is not linked from this page.

There is no public build published yet

When there is, it will appear here as a single file, alongside its SHA-256 checksum and its Authenticode signature, and this page will tell you how to check both. Until then this button has nothing to hand you, and we are not going to pretend otherwise by linking you to a test build that has not yet been through enough real computers.

If you build from source in the meantime, src/aurbridge/ builds both the read-only check and the installer. The check returns exit code 0 for go and 1 for blocked.

What Windows will say when you run it

Honestly: for now, it will warn you. Windows shows “unknown publisher” for any program whose publisher has not yet been verified by a certificate we have to buy from a certificate authority, and on a recently-installed Windows 11 with Smart App Control switched on, an unsigned program is not merely warned about — it is refused outright.

We are not going to write a page teaching non-technical people to click past their operating system’s security warnings. That habit is worth more to them than we are. The correct fix is on our side: buy the certificate, sign the binary, and build the reputation. Until that is done, this software is for people who are comfortable checking a checksum.

Hard requirements

Each of these is a hard stop in the installer, with no “advanced” checkbox and no override. If your PC fails one, AurBridge tells you which one and what to do about it, and then it stops.

Checked before anything is touched. All of these are read-only tests.
We require Because If you fail it
UEFI firmware On legacy BIOS there is no one-shot, self-reverting boot attempt. A bad boot record means a blinking cursor and no way back. Refused. Some PCs can be switched to UEFI in firmware settings, but that is a change we will not talk you through.
Administrator rights Reading raw disk structures and firmware variables needs them. Right-click, “Run as administrator”.
Mains power, battery above 50% Power loss during repartitioning is unrecoverable in the worst case. Plug in and charge. Then re-check.
About 28 GB free Room for the system, your files, and the rescue partition that can put Windows back. Empty the Recycle Bin, run Disk Cleanup, move large files off. Then re-check.
Fast Startup switched off Windows “shut down” usually hibernates instead. If it later resumes from that saved image after we have changed the disk, it writes back a stale map of the disk and destroys both systems — silently, hours later. Refused until it is off and the machine has been genuinely restarted. The installer verifies that, it does not take your word for it.
No pending Windows updates A half-applied update finishing after we repartition is the same class of problem. Let Windows finish updating and restart.
A healthy drive We read the drive’s own error counters. Pending or uncorrectable sectors mean the disk is failing now. Refused, with no override. Back your data up today, on any machine, and replace the drive.
A clean, non-encrypted-by-strangers filesystem Feeding a damaged filesystem into a resizer turns a few unreadable files into an unmountable disk. Third-party whole-disk encryption sits underneath everything we would do. Refused on a dirty filesystem until a full disk check passes. Refused outright under third-party disk encryption.
One ordinary disk layout Windows dynamic disks and Storage Spaces keep the real layout somewhere our tools do not read. Intel RST remapping can hide the drive from Linux entirely. Refused on dynamic disks. Warned on Intel RST, and verified from the rescue environment before anything is committed.
External drives unplugged The single cheapest way to prevent writing to the wrong disk. Unplug them. You will also be asked to type the size or label of the target disk back.
Your BitLocker key, if the drive is encrypted Changing the disk layout changes what the security chip measures at boot. Windows will then ask for a 48-digit key most people have never seen. Refused if the key cannot be produced. This one has cost people their entire Windows install elsewhere; we will not risk it.

Secure Boot being switched on is a warning rather than a block, and it has a real consequence: on first boot you will see one firmware screen asking you to approve our key. Why that screen exists.

If we refuse your PC

Being refused is a designed outcome, not an error. It means the check worked.

What a refusal gets you

A named reason, in plain English, with what would have to change. Not a code, not a dialog box with an OK button. Several of the refusals — a failing drive especially — are worth knowing about whether or not you ever install Linux.

A person told “your hard drive is failing, back up today” is a person we helped. A person whose drive dies during our install is one we harmed.

What you can do instead

  • Failing drive: back up now. A replacement SSD for an old laptop is inexpensive, and afterwards the PC qualifies and is faster than it has ever been.
  • Not enough space: Disk Cleanup, empty the Recycle Bin, move video and photo archives to an external drive.
  • Legacy BIOS: a mainstream distribution installed from a USB stick is a better fit for that machine than we are. We would rather say so than take the risk.
  • No USB stick and no backup: fix that first, for reasons that have nothing to do with us.

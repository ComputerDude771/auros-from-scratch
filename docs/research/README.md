# Research

Findings that inform design decisions. Each file is a point-in-time
research report; where a claim drives code, it is cited from the relevant
component. Reports were produced with web verification of paths, APIs,
costs, and prior art — but they are research, not gospel: verify before
betting user data on any single line.

- `migration.md` — the Windows→Linux data-migration map (Ferry's spec)
- `windows-installer.md` — one-reboot in-place install mechanics (AurBridge)
- `signing-trust.md` — Secure Boot + Authenticode prerequisites
- `red-team.md` — adversarial risk register

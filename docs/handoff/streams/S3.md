# S3: memory safety of our own C code (handoff)

For an engineer with zero context. Brief: `docs/handoff/STREAMS.md`, row S3.
Branch: `claude/brave-hypatia-x72g1m` only. Last updated: see `git log -1 -- docs/handoff/streams/S3.md`.

## Goal

Fuzz every parser of untrusted input we wrote, under ASan+UBSan, fix every
crash with a regression test, then add hardening compiler flags to every C
build and prove them with a checksec-style test.

Targets: `src/common/font.c` (TrueType/CFF rasteriser), `src/common/theme.c`
+ `wall.c` (her `~/.config` copy of shell.conf is writable by any program she
runs, so theme numbers are hostile input), `src/aurshell/draw.c` (what those
numbers flow into), `.desktop` parsing in `src/aurshell/apps.c`, and the
Wayland compositor `src/aurwl/aurwl.c` against malicious clients.
`src/aurbridge/inflate.c` belongs to stream A2: send them reproducers, don't
edit it. (`src/common/png.c` is a writer only; its input is ours.)

## Done and pushed

- `tools/fuzz/`: `fuzz_font.c`, `fuzz_theme.c` (theme + wallpaper + every
  draw.c primitive), `fuzz_desktop.c` (includes apps.c whole; real
  `shell_scan_apps`/`shell_rescan_apps` under kiosk policies),
  `standalone.c` (runs any harness over files with plain gcc, no libFuzzer),
  `build.sh`, `mkseeds.py` (subsets system fonts with fontTools), seed
  corpora `tools/fuzz/corpus/{font,theme,desktop}` (~112 KB).

## Crashes found / fixed

| # | Where | What | Status |
|---|---|---|---|
| 1 | `src/aurshell/draw.c:94` (`draw_rect`) and the same pattern in every clip in draw.c | signed overflow `r.x + r.w` when a theme number is near INT_MAX; NaN/huge float-to-int casts (`(int)ceilf(...)`, `draw_blend_px` with NaN alpha) | found on seed `corpus/theme/extremes.theme`; fix in progress |

Note: draw.c writes go through bounds-checked `draw_blend_px`, so #1 is UB, not
an out-of-bounds write.

## Half-done / not pushed

- Fix for #1: 64-bit `clip_span()` + NaN-safe `clampf()` + clamped float casts in
  draw.c; `theme_int` saturating and `theme_num` refusing nan/inf in theme.c;
  clamp theme numbers to sane ranges in `shell_theme_load` (shellcommon.c);
  NaN-safe wall.c. Real themes use radius<=18, border 2, bar_height 38,
  blur/shadow 0, opacities 0..1, so ranges like radius 0..64 change nothing.
- `fuzz_aurwl.c` not written yet (plan below).

## Next 5 steps

1. Land fix #1 with a regression input in `tools/fuzz/regress/theme/` and a
   `tools/fuzz/regress.sh` that builds `MODE=regress` and runs every harness
   over `corpus/*` + `regress/*` (fails on any sanitizer report).
2. Fuzz font, theme, desktop for a bounded time each (one at a time,
   `nice -n 19`, e.g. `-max_total_time=900 -rss_limit_mb=2048 -timeout=10`),
   fix findings, add each reproducer to `regress/<target>/`, minimise corpora
   (`-merge=1`) and commit them if small.
3. Suspected in font.c (unconfirmed): composite glyphs recurse to depth 6 with up
   to 64 components and no shared budget, so a self-referencing composite costs
   up to 64^6 calls (a hang). Fix: one component budget per glyph, like the CFF
   `MAX_T2_OPS`.
4. `fuzz_aurwl.c`: aurwl in-process (`aurwl_create`, XDG_RUNTIME_DIR in
   scratch), clients over `socketpair` + `wl_client_create`, requests built
   from the generated interface signatures so they pass libwayland's checks;
   destroy clients at the end of each input and assert the compositor is back to
   empty (no surfaces, focus NULL, selection NULL). `build.sh` already builds it
   if the file exists.
5. Hardening flags in `build/forge` (in-chroot gcc lines) and `build/staging`
   (static: use `-static-pie`): `-O2 -D_FORTIFY_SOURCE=3
   -fstack-protector-strong -fstack-clash-protection -fcf-protection=full
   -fPIE -pie -Wl,-z,relro,-z,now`; a checksec-style test (`readelf -d`/`-l`,
   `__stack_chk_fail`, `_chk` symbols, GNU_RELRO + BIND_NOW, PIE type DYN,
   `.note.gnu.property` IBT/SHSTK) that fails on a binary built without them.
   Then send A2 any inflate.c reproducers.

## Traps

- The container has clang 18 but no libFuzzer runtime by default:
  `apt-get download libclang-rt-18-dev`, then `apt-get install -f` (it needs
  lib32stdc++6/libc6-i386; a half-configured package breaks every other
  agent's apt).
- CPU is shared by ~15 agents: one fuzzer at a time, `nice -n 19`, bounded time.
- Ubuntu's gcc already defaults to some hardening (FORTIFY, stack protector),
  so a "flags are on" test passes on Ubuntu even without our flags. Prove the
  test fails with `-U_FORTIFY_SOURCE -fno-stack-protector -no-pie -Wl,-z,lazy`.
- fontTools is not installed; `pip install --target <scratch>/pylib fonttools`.
